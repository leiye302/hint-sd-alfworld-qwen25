# Sources and scope

- **HINT-SD** — <https://github.com/wgcyeo/HINT-SD>, commit `bc95b44192b06328a88773dbf3b345fa1c499093`, Apache-2.0. Authors: Woongyeong Yeo, Yumin Choi, Taekyung Ki, Sung Ju Hwang. Paper: <https://arxiv.org/abs/2605.17873>. All original source files are fetched unchanged; individual hashes are locked in `configs/upstream.json`. Inherit its loss, top-k/tail approximation, token reduction, microbatch backward, EMA, feedback parser, selected-step construction, PEFT save/load and Hugging Face training framework.
- **SDAR / verl-agent ALFWorld environment** — <https://github.com/ZJU-REAL/SDAR>, commit `29dcb12a55d8fc17ba6ae03fd0a69048f43051f3`, Apache-2.0. Only its ALFWorld TextWorld class/support modules, config, observation/action prompt, and native action parser are used. No SDAR/RLSD trainer, advantage, skill bank, GRPO loss or gate is used. The native files retain their NTU / verl-agent copyrights.
- **ALFWorld** — <https://github.com/alfworld/alfworld>. Official `alfworld-download` provides the separately licensed games/resources. `alfworld==0.4.2` in a separate CPU environment supplies its dependencies and downloader; runtime selects the pinned SDAR public ALFWorld package. No proprietary annotations or author-local assets are required.
- **Qwen** — <https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct> (Apache-2.0) and <https://huggingface.co/Qwen/Qwen2.5-3B-Instruct> (Qwen Research License). Revisions are in `configs/models.json`; read the original model licenses before downloading/using weights. No weights are included here.
- **Shared evaluation manifest** — the public fixed `valid_seen` 140-task protocol shared with the SDAR/RLSD ALFWorld comparison wrappers. Contains public relative game paths, seeds and SHA-256 only; not a private training dataset or benchmark result.

The original HINT-SD experiments use BFCL/AppWorld and primarily a Qwen3-4B model. This adaptation changes environment/model/validation budget and device placement, not the claimed original algorithm. Qwen2.5-1.5B ALFWorld results are not author-published results. See README for all runtime and budget differences.
